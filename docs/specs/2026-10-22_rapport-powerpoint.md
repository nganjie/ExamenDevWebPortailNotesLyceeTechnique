# Spec — Rapport PowerPoint

- Date : 2026-10-22
- Exigences couvertes : `G-LIV-1`, section 11 du cahier des charges (structure attendue du rapport)

## Besoin

Le rapport de projet sous forme de diaporama (15 à 25 diapositives), lisible seul, qui sert aussi de support à l'exposé.

## Structure (20 diapositives, ordre imposé par le sujet)

1 page de garde (auteur) · 2 contexte · 3 objectifs · 4 plan du site · 5-6 base de données ·
7 routes · 8-13 réalisations (bulletin, rangs ex æquo, saisie, correction, statistiques, administration
et import) · 14 adaptatif · 15 JavaScript et API · 16 sécurité (saisie refusée) · 17 validation ·
18 difficultés · 19 organisation du travail personnel · 20 conclusion.

Le projet est un **travail individuel** : le rapport ne le présente jamais comme un travail de groupe.

## Règles

- Captures prises dans le navigateur (Chromium) sur http://127.0.0.1:5000, **recadrées** sur l'essentiel,
  chacune accompagnée d'une phrase qui dit ce qu'elle montre.
- Couleurs et icônes de l'application ; extraits de code courts et lisibles.
- Les informations personnelles (nom, prénom, matricule, filière, niveau) sont marquées
  `[À compléter]` : l'auteur les remplit.
